# Índice de specs

> Una fila por feature, sin excepciones. `product-analyst` la actualiza al escribir el spec (`Draft`), al
> aprobarlo (`Aprobado`), al integrarlo (`Shippeado`), y al marcarlo `Superado por <id>` cuando un spec
> nuevo reemplaza su comportamiento. Nunca se borra una fila ni una carpeta de spec — este índice es la
> única tabla que hace falta mirar para saber qué está vigente, en vez de recorrer carpeta por carpeta.
