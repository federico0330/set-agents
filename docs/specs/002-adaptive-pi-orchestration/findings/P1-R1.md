# P1-R1 consolidated findings

Verdict: `repair_required`.

## Root-cause groups

1. **Trusted catalog and authentication** (`P1-R1-001`, `P1-R1-003`, `SEC-001`)
   - Routes, provider/model/family relations, unique IDs, ranks, tools, tiers, allowed state, and observed OAuth
     must be validated catalog facts.
   - Configured subscription flags are not proof of observed authentication.
   - `gpt-5.6` and `gpt-5.6-sol` canonicalize to Sol; Pi execution eligibility needs enabled+authenticated Sol/medium.

2. **Strict envelope and trusted observations** (`P1-R1-002`, `SEC-002`)
   - Reject unknown keys and invalid types/enums.
   - Harness-owned role/tool/context/read-write/critical-surface observations override caller claims.
   - Contradictions and ambiguous critical work escalate to `feature/frontier`.

3. **Effort, ranking, exclusions, reviewer independence** (`P1-R1-004`, `P1-R1-005`)
   - `xhigh` only for benchmark-enabled auditor/judge; never `max`.
   - Independent alternate provider precedes normal ranking for reviewer work.
   - Preserve exclusion reasons and record why a non-rank-1 route was selected.
   - Cold start uses curated priority; populated metrics rank by success then p50/p90, with quota/cost tie-breaks.

4. **Sealed gates and proportional plans** (`P1-R1-006`, `SEC-003`)
   - Versioned immutable `GateSpec`: trusted executable, argv, repository real cwd, allowlisted environment.
   - No ambient PATH/cwd resolution and no raw shell.
   - Enforce each lane's required/forbidden spawns, roles, gates, reviewer, checkpoint, continuation, and exit rules.

5. **Schema exactness** (`P1-R1-007`)
   - Reject booleans where integer values are required, invalid ranges, duplicate/unknown providers, and invalid
     combinations. Keep schema-1 normalization and schema-2 emission atomic/idempotent.

6. **Durable execution and fallback authorization** (`P1-R1-009`, `SEC-004`)
   - Persist decision before dispatch; atomically consume a one-use authorization.
   - Sticky partial-write state permanently denies fallback.
   - At most one fallback authorization; replay/concurrency must fail closed.
   - Terminal persistence failure returns a redacted safe checkpoint.

7. **Telemetry value safety and filesystem integrity** (`P1-R1-008`, `SEC-005`, `SEC-006`, `SEC-007`)
   - Closed outcome/reason enums and bounded numeric counters only.
   - Reject symlinks/broken links, require owned regular files, no-follow opens, private modes, process-safe locking,
     exclusive one-time salt creation, collision-proof rotation, and directory fsync.

8. **Retention, aggregation, and reporting** (`P1-R1-010`)
   - Rotate by segment/oldest-record age, not append-refreshed mtime, with bounded append cost.
   - Preserve privacy-safe aggregates across rotation.
   - Report p50/p90 duration, success, spawns, tool calls, token/cost availability, fallbacks/outcomes, excluded
     models/reasons, and artifact correctness with deterministic empty-sample values.

9. **Stable CLI failures** (`P1-R1-011`)
   - Invalid input/config → exit 2; diagnosed unavailable/unhealthy → exit 1; success → 0.
   - Malformed/unreadable telemetry returns a versioned envelope without traceback.

10. **Regression coverage** (`P1-R1-012`)
    - Table-driven coverage for every group above, provider outage, Claude-only, Sol aliases, partial write,
      concurrency/replay, symlink/race/value injection, all lane plans, schema types/ranges/atomic failure, rotation,
      populated reports, CLI exits, and exclusion explanations.
