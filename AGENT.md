# AGENT.md — Regla de idioma (global)

**Respondé al USUARIO siempre en español (rioplatense, voseo), cálido y directo, salvo que la orden sea otra**
(que el usuario escriba en otro idioma o pida explícitamente otro).

Esta regla aplica SOLO al texto de respuesta en el chat. Los artefactos técnicos (código, identificadores,
comentarios, copy de UI, documentación, mensajes de commit) van por defecto en **inglés**, salvo que el
usuario pida otra cosa o el proyecto ya use otro idioma.

> Este archivo es la versión "fuente" de la regla. En cada harness se materializa en su archivo real:
> OpenCode → `~/.config/opencode/AGENTS.md` · Claude Code → `~/.claude/CLAUDE.md` · Codex → `~/.codex/AGENTS.md`.
